## Part A — Member-app simplicity and design

**A1 Baseline.** Capture desktop and 390px screenshots of the current member surfaces before any edit, so before/after hierarchy can be shown.

**A2 Navigation.** One hierarchy across desktop and mobile with five primary destinations: Today, Meals, Progress, Ask/Help, More. Each maps to the existing route (no duplicates). More is grouped as: Learn and tools (Learn, Library, Workouts where active); Community; Account and help (Profile, Billing, Settings, Support). Billing, Settings, Support, export and deletion stay reachable during billing restriction; Settings stays reachable during deletion restriction, driven by the existing account-surface evaluator and route precedence (`src/lib/appSurfaces.ts`, `src/lib/membership.ts`) — no component re-derives status. Fasting scheduling and Supplements do not return to primary navigation, onboarding, Today or the first-14-day journey; the education-only fasting guide stays reachable through Learn only. Disabled or empty tools are not surfaced to fill space. Every destination gets an accurate accessible label and active state.

**A3 Today dashboard.** Reorder to: calm greeting and short orientation → one visually dominant Today's Action card → a small row of existing logging shortcuts (blood glucose, meals, activity/habit — no new data fields) → one compact progress summary → secondary content. Only one primary call to action above the fold. Today's Action stays usable when catch-up exists. Streak, ring, level, XP and phase summaries are combined into a single progress element; detailed levels, badges and streak history move to Profile or a collapsed section; habit rings remain as supporting detail only. Upcoming days and journey previews sit below the current action or inside a collapsed journey section. Catch-up is collapsed by default with a neutral count and optional disclosure — no shame, urgency or failure language. Wording is "Daily Action Streak", never "Reversal Streak". No member data, achievement history, completed-state functionality or database fields are removed.

**A4 First use and Days 1–3.** Onboarding keeps only the fields the working membership needs (no fasting, supplement, medication-clearance or extra health questions), shows current step and what remains, and lands directly on Today's Action. Days 1–3 each present one main action plus supporting explanation and optional logging. Inline guidance uses existing UI patterns rather than a new tutorial system. Empty states explain the next step; error states offer recovery and preserve entered input where safe; loading states never look like empty data or failure.

**A5 Core screens.** Meals: ideas and plans easy to find, next useful action obvious, AI-generated labels/safety notes/reporting preserved, advanced generation and export behind a secondary action, no supplement or fasting plan modes. Progress: one clear summary before detailed charts, doctor report stays inside Progress, charts get text summaries, non-color-dependent legends and accessible table equivalents where practical, S1 classifications preserved, no new urgent-high rule. Ask/Help: public VITA widget stays the Stage 0 deterministic membership helper; the signed-in Ask screen describes only what is enabled today and — with health AI disabled — makes no personalized-health promise, keeps emergency/medication boundaries, AI-generated/educational labels and reporting, and keeps safe paths to support and community questions; no invented credentials or "expert-reviewed" wording. Community: honest empty state, no fabricated activity or members, stays under More, moderation and privacy controls intact. Account screens: consistent headings, actions and status language across Billing, Profile, Settings and Support; signed-in members are never sent to Login because of billing status; billing-restricted, dispute-restricted and deletion-restricted states get calm explanations and clear recovery; export, deletion, cancellation and support stay findable.

**A6 Terminology.** Standardize on Today's Action, Daily Action Streak, Progress, Meals, Ask VITA or Help (matching the enabled capability), Build Your Routine, educational membership. Remove active member-facing remnants of Reversal Streak, "Phase 3 — Reversal", reverse/reversal as a promised benefit, 7-Day Reset and 7-Day Reset Sprint, guaranteed or typical medical outcomes, unsupported expert/rating/testimonial/member-count claims, and mandatory fasting or supplement language.
